# Demo Test Skill — Claude Code 技能系统验证

全面验证 Claude Code Skill 系统核心能力的测试工具。

## 何时使用

- 用户说"测试 demo skill"、"运行 demo 测试"
- 用户说"验证 skill 系统"、"demo 测试"
- 新环境部署后，验证 skill 加载链路是否正常
- 验证 Claude Code 各项工具是否可用

## 执行步骤

当被触发时，按顺序执行以下验证，并最终输出验证报告。

---

### 阶段 1：基础响应验证

回复用户一条欢迎信息，确认 skill 已被正确加载和触发：

```
🎯 Demo Test Skill 已成功加载并触发！
```

### 阶段 2：环境信息收集

收集并输出当前运行环境的基本信息：

1. **工作目录**：当前 session 的工作目录路径
2. **操作系统**：通过 `Bash` 运行 `uname -s` 或 `ver` 获取
3. **日期时间**：当前日期和时间
4. **Shell 类型**：当前使用的 shell

### 阶段 3：文件读写能力验证

1. 在 `d:/06_Project/skills_sync/skills/demo-test/` 目录下创建 `test-output.txt`
2. 写入内容：当前时间戳 + 技能执行计数（每次执行追加一行）
3. 读取文件验证写入成功
4. 输出验证结果

### 阶段 4：工具链能力验证

通过以下操作验证 Claude Code 核心工具可用：

| 工具 | 验证方式 | 说明 |
|------|---------|------|
| `Read` | 读取 SKILL.md 自身 | 验证文件读取 |
| `Write` | 写入测试文件 | 验证文件写入 |
| `Bash` | 执行简单命令 | 验证 Shell 执行 |
| `Glob` | 查找 skills 目录 | 验证文件搜索 |
| `Skill` | 列出可用 skill | 验证 skill 工具 |

### 阶段 5：综合报告输出

输出格式化的验证报告：

```
╔══════════════════════════════════════════════╗
║     🧪 Demo Test Skill 验证报告              ║
╠══════════════════════════════════════════════╣
║ [✅/❌] 1. Skill 加载与触发                  ║
║ [✅/❌] 2. 环境信息读取                      ║
║ [✅/❌] 3. 文件读写能力                      ║
║ [✅/❌] 4. Read 工具                         ║
║ [✅/❌] 5. Write 工具                        ║
║ [✅/❌] 6. Bash 工具                         ║
║ [✅/❌] 7. Glob 工具                         ║
║ [✅/❌] 8. Skill 工具                        ║
╠══════════════════════════════════════════════╣
║ 总计: N/8 通过                               ║
╚══════════════════════════════════════════════╝
```

## 支持文件

- `test-output.txt` — 每次测试生成的日志文件（记录执行历史）
