# Unisoc-PPT Skill 创建过程与要点

## 项目背景

### 需求分析
- 需要一个基于紫光展锐官方模板的 PPT 自动生成技能
- 输入：结构化大纲（Markdown 或 JSON）
- 输出：符合企业 VI 规范的 .pptx 文件
- 要求：封面、目录、章节过渡、内容页、尾页自动编排

### 现有资源盘点
- 官方模板：紫光展锐企业PPT模板（中文）-2506.pptx（29页，10种版式）
- 参考技能：Powerpoint-PPTX skill（Anthropic 官方，通用 PPT 操作规范）
- 参考截图：referenceppt 目录下的 skill 制作教程

## 模板逆向分析

### 版式提取
- 使用 python-pptx 库逐页分析模板
- 识别出 10 种 Slide Layout：封面页、过渡页1-6、标题居中页、目录页、1_标题居中页
- 记录每种版式的 Placeholder idx、位置、尺寸

### 品牌规范提取
- 主字体：微软雅黑（所有文本）
- 品牌色：#920784（Unisoc 紫）— 封面标题、章节编号
- 标题色：#262626、正文色：#404040、辅助色：#130000
- 尺寸规格：16:9（960cm × 540cm），emu 单位换算 1cm = 360000 EMU

### 内容结构归纳
- 封面 → 目录 → 章节过渡页 → 内容页（×N）→ 尾页
- 内容页版式为"标题居中页"（Layout 7），只有标题占位符，正文需手动添加文本框
- 段落字体必须逐 run 显式设置，不能依赖模板继承

## 技能架构设计

### 文件结构
- SKILL.md：技能入口，frontmatter + 7 条核心规则 + 3 种工作流
- references/template-layouts.md：完整版式目录 + 29 页逐页清单
- scripts/inventory_template.py：模板分析工具
- scripts/gen_unisoc_ppt.py：主生成器

### 生成器核心函数
- make_cover()：封面页，标题紫色加粗、副标题含日期地点密级
- make_toc()：目录页，自动双列布局，编号 01-0N
- make_section()：章节过渡，6 种版式轮换，编号+标题
- make_content()：内容页，≤4 条大字号单列，>4 条分双列
- make_closing()：尾页，"用芯成就美好世界"+ URL

### 输入格式设计
- Markdown：H1 标题、H2 章节、H3 内容页、列表为正文
- JSON：type 字段区分 cover/toc/section/content/closing
- 自动补充 TOC 和 closing，用户无需手写

## 关键技术要点

### 模板克隆策略
- 必须基于官方模板创建，不能从空白 PPT 开始
- 克隆后删除原模板的 29 页示例幻灯片，保留版式和母版
- 使用 slide_layouts 添加新页，版式索引固定对应

### 字体处理
- 每个文本 run 必须显式调用 run.font.name = '微软雅黑'
- 不能信任母版字体继承——模板主题中定义的是"等线"，需覆盖
- 中文字体同时设置 Latin 和 East-Asian typeface

### 版式选择规则
- Layout 0 仅用于封面，Layout 7 用于所有内容页
- Layout 1 过渡页无占位符，需手动添加文本框
- Layout 2-6 过渡页有 idx=10（编号）+ idx=12（标题）两个占位符
- Layout 8 目录页、Layout 9 尾页均无占位符

### QA 检查清单
- 所有文本字体是否为微软雅黑
- 封面标题是否为 #920784 紫色
- 有无残留模板占位文本
- 标题大小是否统一
- 幻灯片数量是否 = 封面 + 目录 + 章节页 + 内容页 + 尾页

## 验证结果

### 测试用例
- 输入：5 个章节、8 个内容页的 Markdown 大纲
- 输出：14 页 PPT（1 封面 + 1 目录 + 4 章节过渡 + 7 内容 + 1 尾页）
- 版式正确应用、颜色规范合规、字体全部为微软雅黑

### 已确认可用的功能
- Markdown → PPTX 一键生成
- JSON 结构化输入
- inventory_template.py 模板分析工具
- 6 种过渡页版式自动轮换
- 内容自适应单列/双列布局
