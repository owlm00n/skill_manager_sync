# Bug 知识库

> **索引模式**：本目录只记录 Bug ID + 基本信息 + 链接。具体根因和修复方案由 AI 在分析时重新判断，不预判结论。

## 索引规则

1. 每个 Bug 一个文件，命名为 `<BUG_ID>.md`
2. 只记录：Bug ID、标题、测试项、失败现象摘要、相关链接
3. **不记录**：根因推测、修复方案、代码改动建议（这些由 AI 每次分析时重新判断）
4. 如有历史分析报告，以链接形式引用，AI 需自行评估其时效性

## 文件格式

```markdown
# Bug <BUG_ID>

- **标题**: <title>
- **测试项**: <CASE_ID>
- **平台**: <platform>
- **现象**: <一句话描述失败现象>
- **链接**: <bug 管理系统 URL>
- **相关报告**: <可选，历史分析报告路径>
```
